# 截圖指引

每個專案把自己的截圖放在**自己的 repo**，apex-code 同步時複製過來，放進 API 與介紹頁。
這份指引可以直接交給各專案的開發者（或那個專案的 Claude）照做。

## 放在哪裡

```
<專案 repo>/docs/screenshots/
├─ 01-<說明>.png            沒有語言差異的截圖
├─ 02-<說明>.zh-TW.png      有語言差異：中文版
├─ 02-<說明>.en.png         有語言差異：英文版（和中文版同編號同說明）
└─ captions.json            每張截圖的中英文說明
```

- 編號決定順序，**`01` 是卡片封面**，請放最能代表這個專案的畫面。
- `<說明>` 用小寫英文與連字號，例如 `01-main-window.png`。
- 同一個編號只能有「一張無語言」或「zh-TW + en 兩張」其中一種。

## 規格

| 項目 | 規定 |
|---|---|
| 比例 | **16:10** |
| 尺寸 | 1280 × 800（建議）；高解析可用 2560 × 1600 |
| 格式 | PNG（介面）或 WebP；單張 1 MB 以下 |
| 張數 | 1–5 張 |
| 內容 | 只截應用程式本身的視窗或畫面，不含桌面、工作列、其他程式 |
| 資料 | 用示範資料：不能出現真實的使用者名稱、路徑、Email、Token、帳號 |

**封面（01）注意事項**：介紹頁會把封面裁成 16:10 並對齊左上角，重要內容請放在畫面左上方。

### 各類專案的截法

| 類型 | 截什麼 |
|---|---|
| 桌面程式 | 主視窗；視窗大小調成 1280 × 800 再截 |
| 輸入法、疊加層這類沒有主視窗的工具 | 實際使用時的畫面（例如候選窗出現在編輯器上），裁成 16:10 |
| 網頁服務（Docker 自架） | 瀏覽器視窗內容，瀏覽器縮放 100%、視窗內容 1280 × 800 |
| 瀏覽器腳本或擴充 | 套用在目標網站上的畫面，並把個人資訊遮掉 |
| VS Code 擴充 | VS Code 視窗，使用預設深色主題 |

## captions.json

```json
{
  "01-main-window": { "zh-TW": "主視窗", "en": "Main window" },
  "02-settings": { "zh-TW": "設定", "en": "Settings" }
}
```

鍵是去掉編號以外的副檔名與語言後的檔名（`01-main-window.png` → `01-main-window`）。

## 同步

截圖放好並推上 GitHub（或存在本機）後，在 apex-code 對 Claude 說「更新 <專案 id>」，
它會把截圖複製到 `apex-code/screenshots/<id>/` 並寫進 `api/v1/projects.json`。
